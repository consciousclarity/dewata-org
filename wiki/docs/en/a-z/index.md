# Dewata.org A–Z index

The complete index of terms used by the dewata.org project. Each
entry below is one term page; pages are ordered by `canonical_slug`.

Note: this index is generated by
[`scripts/build_coverage_report.py`](../../scripts/build_coverage_report.py)
and saved to [`build-artifacts/coverage.json`](../../build-artifacts/coverage.json)
at each build. This root page is the markdown rendering of that
coverage report, with hyper-links to each term.

## How to read

- Each row lists `canonical_term`, category, and status.
- Each term maps to three translated pages: `/<lang>/<slug>/...`.
- Status `verified_source` means the page is sourced from an
  existing repository document.
- Status `disputed` means the page references an active dispute
  id in `phase-1/docs/runbook/disputes.json`.
- Status `implementation_definition` means the page describes the
  behaviour of `phase-1/src/dewatacalendar/`, not customary truth.
- Status `pending_customary_review` means the page needs a
  customary review before its status can be finalised.
