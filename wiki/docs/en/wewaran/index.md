# Wewaran (day-classification cycles)

Wewaran are ten concurrent day-classification cycles in the Balinese calendar. Each cycle has a different length (2 to 10 days), and a day's position in each cycle produces a unique combination used to determine the character or significance of that day.

## Cycle index

| Cycle | Name | Length |
|-------|------|--------|
| Ekawara | 1 | 1 day |
| Dharma | 2 | 2 days |
| Trivara | 3 | 3 days |
| Caturwara | 4 | 4 days |
| Pancawara | 5 | 5 days |
| Sadwara | 6 | 6 days |
| Saptawara | 7 | 7 days |
| Astawara | 8 | 8 days |
| Sangawara | 9 | 9 days |
| Dasawara | 10 | 10 days |

## Urang (values)

Each wewaran cycle carries a numeric value (urang) used in calendar calculations. Urip values per cycle:

| Cycle | Urang |
|-------|-------|
| Ekawara | 1 |
| Trivara | 3 |
| Caturwara | 4 |
| Pancawara | 5 |
| Sadwara | 6 |
| Saptawara | 7 |
| Astawara | 8 |
| Sangawara | 9 |
| Dasawara | 10 |
